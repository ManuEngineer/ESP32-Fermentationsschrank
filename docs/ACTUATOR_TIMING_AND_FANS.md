# Veralteter Dateiname

Dieses Dokument enthaelt keine eigene Spezifikation.

Die verbindliche Spezifikation fuer Schaltfenster, Mindest-Einschalt- und
Mindest-Ausschaltzeiten, Richtungswechsel, Totzeit und Luefterlogik steht in
[`ACTUATOR_TIMING.md`](ACTUATOR_TIMING.md).

Verweise auf `ACTUATOR_TIMING_AND_FANS.md` sind historische beziehungsweise
kompatible Verweise und muessen bei einer inhaltlichen Aenderung auf den
kanonischen Dateinamen aktualisiert werden.
