# Auditdokumente

Die Dateien in diesem Verzeichnis dokumentieren historische Recherchen,
Bewertungen, Kandidatenvergleiche und damalige Roadmapvorschlaege. Sie sind
keine aktuelle Projekt- oder Taskuebersicht.

Der aktuelle Arbeitsstand steht ausschliesslich in
[`../ROADMAP.md`](../ROADMAP.md). Verbindliche Architektur- und
Produktentscheidungen stehen in akzeptierten ADRs, dem ADR-Register und den
kanonischen Fachvertraegen.

Auditbefunde duerfen fuer eine neue Evaluation herangezogen werden, muessen aber
gegen aktuelle Toolchain, Hardware, Live-Issues, Herstellerquellen, Lizenzen und
den aktuellen Repositorystand neu verifiziert werden.
