# Aufgabenplaene

Die Dateien in diesem Verzeichnis sind versionierte Plaene einzelner Pull
Requests oder Arbeitspakete.

## Aktueller Plan

Ein Plan ist nur dann aktuelle Handlungsgrundlage, wenn er im offenen
Live-Pull-Request genannt ist und sein exakter Commit vom Owner freigegeben
wurde. Der aktuelle Projektstand und die Reihenfolge stehen in
[`../ROADMAP.md`](../ROADMAP.md).

## Abgeschlossene oder ersetzte Plaene

Nach Abschluss, Schliessung oder Ersatz des zugehoerigen Pull Requests bleibt
eine Plan-Datei ausschliesslich als historischer Auditnachweis bestehen. Darin
genannte damalige Statusangaben, Dateipfade, Auftragsvorlagen, Branches,
Abhaengigkeiten und naechste Schritte sind nicht automatisch aktuell.

Historische Plaene duerfen fuer Herkunft und Begruendung gelesen werden, muessen
aber gegen Live-Issue, Pull Request, aktuelle ADRs, kanonische Fachvertraege und
den aktuellen Repository-Head verifiziert werden.
